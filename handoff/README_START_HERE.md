# glmDev.com — Codex implementation handoff

This is a **design and implementation brief**, not a finished website. The approved homepage mockup is `design/APPROVED_HOMEPAGE_REFERENCE.png`. The AI training section close-up is `design/AI_TRAINING_SECTION_DETAIL.png`.

## How to use with Codex Desktop
1. Extract this ZIP into a local folder (for example `glmdev-website`).
2. Open that folder as your Codex Desktop workspace.
3. Paste the contents of `PROMPT_FOR_CODEX.md` as your first instruction, or tell Codex to read and follow it.
4. Review the generated website locally, iterate, then deploy to Bluehost following `BLUEHOST_DEPLOYMENT.md`.

No GitHub repository is required for this workflow. Codex Web may have repository/environment requirements; this package is intended to work especially well with Codex Desktop and a local folder.

## Files
- `PROMPT_FOR_CODEX.md` — executable build brief and acceptance criteria
- `CODEX_HANDOFF.md` — background, design, architecture, scope
- `CONTENT_AND_SECTIONS.md` — initial site copy and structure
- `BLUEHOST_DEPLOYMENT.md` — hosting and mail configuration notes
- `design/` — visual references, **not production website assets**

The mockups are concept art and may contain illustrative UI and fictional project metrics. Do not represent those as real client outcomes. The images are reference-only; implement the page as accessible HTML/CSS/JS, not as a giant screenshot.
